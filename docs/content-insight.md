# 智识第一版：使用与验收

本实现面向通用办公、浏览器和触屏操作。轮盘上保留固定的「智识」入口，识别结果在独立卡片中展示，不根据当前内容改变轮盘方向。本次发行的主程序版本为 `1.8.0-touch.3`，社区插件版本为 `1.0.0`，需要宿主 SDK 1.5；智识功能也支持 `1.8.0-touch.2`。

## 安装和配置

1. 退出旧版本 StarPie，解压新的主程序包。`Standalone` 自带运行时；`Lightweight` 需要 .NET 8 Desktop Runtime。程序仍读取原有用户配置。
2. 将独立的 `ContentInsight` 插件包解压到一个新目录。打开控制台的插件管理页，使用本地安装入口选择该目录的 `StarPie.Plugin.ContentInsight.dll`，确认能力并启用。保留相邻的 `plugin.json`。主程序不会自动安装此插件。
3. 在常用轮盘选一个固定扇区，动作类型选「插件动作」，具体动作选「智识 / Content Insight → 智识」。若需要快速识屏或读取剪贴板，再通过现有子动作编辑器添加「框选识屏」「识别剪贴板」。方向和原有其他槽位由用户选择。

不要把插件 DLL 放进主程序发布目录作为内建动作，也不要给插件目录复制 `StarPie.Plugin.Abstractions.dll`。宿主负责提供唯一的 SDK 程序集。

## 使用流程

- **已选中文字**：从原应用唤出固定智识扇区。优先读取该窗口的 UI Automation 文本选区；拿不到时出现来源选择卡，可以手动使用剪贴板、框选屏幕或输入。
- **完整网址**：只有来源为文字选区、整段内容均为一个有效网址，而且「完整网址直接打开」已开启时，才直接用默认浏览器打开。关闭该选项后也先显示卡片。剪贴板、输入、多链接和 OCR 来源始终显示卡片，由用户点选。
- **计算**：例如 `200×1.13` 得到 `226`，点击「复制结果」。支持十进制、括号、正负号与四则运算；不执行代码或脚本。
- **文件路径**：支持盘符绝对路径与 UNC 路径。卡片提供打开和定位；只有执行时才检查文件或目录是否存在。不存在或不可访问时保留卡片提示重试。
- **普通文字**：提供搜索、复制原文；段落中的明确 HTTP(S) 链接最多提供四个独立按钮。
- **识屏**：一根手指或鼠标拖动框选，松开后复用现有 OCR 设置。结果显示原文并提醒核对数字、符号和网址；可编辑后重新识别。取消按钮、右键或 Esc 可以取消框选。第二个非按钮触点会取消本次框选。
- **编辑**：只有主动点击「编辑 / 输入」才激活编辑框。修改后立即清掉原操作按钮；点击「识别内容」才生成新按钮。

卡片操作按钮最小高度为 48 DIP，随系统 DPI 放大，支持深浅主题和四种宿主语言。卡片出现时不主动抢占原应用焦点；卡片或框选存在期间暂停轮盘再次唤出，避免触摸嵌套。

## 参数

| 参数 | 默认值 | 用途 |
| --- | --- | --- |
| `searchUrl` | `https://www.bing.com/search?q={query}` | HTTP(S) 搜索网址模板，必须恰好包含一个 `{query}`；关键词进行 URL 编码 |
| `directUrl` | `true` | 明确完整网址选区可直接打开 |
| `copyFallback` | `false` | 允许 UIA 无选区时，向原窗口模拟 Ctrl+C 获取文本 |

Ctrl+C 回退仅在用户打开参数后使用，不直接拿旧剪贴板当选区。执行前检查原窗口仍为前台、剪贴板未发生其它变化；执行后检查序号与所属进程。原剪贴板可保存时先物化为独立快照，读取后仅在没有后续复制覆盖时恢复。复杂未知格式、超过 4 MiB 的快照或 UIA 超时等情况跳过回退，可改用显式来源。密码框不模拟复制。输入上限为 8192 字符。

OCR 沿用当前配置的本地、云端或 AI 提供方；智识不会额外上传屏幕，也不会新建提供方设置。若配置的是云端 OCR，所框选图片按原 OCR 配置交给该提供方。智识结果不会触发原 OCR 动作的自动复制、自动搜索或旧结果窗口。

## 架构与生命周期

- `samples/ContentInsight/InsightRules.cs` 是纯规则模块，不含文件、网络、界面或脚本执行。三个动作都是 Background 类，不占用串行动作线程。
- 宿主 `InsightContentReader` 负责选区和可选复制；`InsightWindow` 负责显示、编辑与确认；`PluginContentInsightService` 负责会话和能力检查。规则插件只引用 SDK 与 BCL，无 NuGet 依赖。
- SDK 通过可选 `IContentInsightContext` 暴露服务，不增加既有 `IPluginContext` 成员。使用 UI、剪贴板、截屏、模拟输入、进程或路径操作时分别检查对应声明。
- 原窗口句柄在手势开始时记录；其标题、进程和触点位置在派发阶段组成运行时上下文，不保存进配置文件。
- 会话运行期间保留插件调用租约。关闭卡片、动作取消、超时或停用插件时解除分类器引用并关闭框选。未结束的宿主 OCR 可继续完成，但不会重新打开已关闭的卡片。网络路径检查在后台执行，检查后再次确认未取消才打开。
- 不注册新的全局钩子，不在鼠标钩子内运行识别或 I/O；未安装智识时只存在按需服务对象，不创建结果窗口。

## 验证与实机检查

无界面测试在 `scratch/ContentInsightTests`，覆盖规则、限制、语言、源窗口快照、剪贴板快照、能力检查、编辑后旧操作撤销、八种主题/语言卡片渲染，以及真实宿主的沙箱安装、启用、注册和完整停用。每次生成独立沙箱并保留，测试不运行旧的 `--plugin-selftest`，也不批量删除文件。测试报告与渲染图随本地发行归档保存。

这些验证没有替代硬件验收。请在自己的设备上按以下顺序检查：

1. 浏览器、Word、记事本和可选中文字的 PDF 分别测试网址、`200×1.13`、普通段落；取不到时应显示来源选择，不误用旧剪贴板。
2. 有意切换前台窗口再触发，检查内容确实来自目标窗口；密码框不能模拟复制。
3. 开启复制回退，用已有富文本剪贴板测试读取与恢复；读取期间再手动复制一次，新内容不能被恢复覆盖。
4. 横屏、两个竖屏与不同缩放下测试单指框选、取消、二指取消，以及按钮边缘点击。
5. 测试 OCR 数字纠错和重新识别、识别期间关闭、停用插件；关闭后不能出现迟到卡片。检查原 OCR 动作仍遵循原设置。
6. 测试存在/不存在的文件、文件夹与网络路径；慢路径期间卡片仍可关闭。测试打开网页、搜索和复制的实际结果。
7. 测试重复触发、应用退出和重新启用插件；检查其它轮盘扇区、Ctrl 按住动作、触控映射和既有热键。

尚未测量新增卡片在实机上的延迟、驻留内存或 120 FPS 表现，不把已有项目目标当作此次性能实测结果。完整 GUI 回归套件仍按 AGENTS.md 由用户手动运行。
