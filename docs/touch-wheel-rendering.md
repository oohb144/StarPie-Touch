# 触屏轮盘外观与绘制优化

适用版本：`1.8.0-touch.3`。沿用原软件的风格与用户配置，补齐触屏软件轮盘先前省略的视觉细节。

## 外观

`NativeWheelScene` 直接复用 `StyleRendererFactory` 的主题色和 `IconHelper` 的形状几何，支持经典圆环、简洁扇区、玻璃配色，以及默认、浅色、抹茶、冰川、莫兰迪和自定义配色。保留圆角、扇区间隔、图标/文字布局、单槽字体/颜色覆盖、中心图案、独立子环主题和轮盘/蜂窝菜单。扇区零号固定正东；视觉几何不参与动作命中判定，原手势状态机保持方向语义。

内置、插件和自定义 SVG 转换成一次构建的 GDI 路径。应用与自定义图片在配置加载/保存时预热，显示时仅查缓存，不读文件、不提取 Shell 图标；缓存缺失时使用矢量回退。场景内栅格图标限制在 128 像素，中心图片限制在 256 像素。不引入 UI 库、浏览器内核或新的全局钩子。

软件呈现使用静态高亮和轻描边光晕，保留透明、触摸穿透、最上层且不抢焦点的窗口属性。WPF 动画、模糊效果、中心背景贴图以及部分动态窗口图标合成仍由 WPF 路径提供；软件呈现不宣称与全部 WPF 特效逐像素一致。`--wpf-touch-wheel` 可切换回 WPF。

## 占用与生命周期

- `Bitmap` 直接封装原生 DIB 指针，像素存储仅有一份。旧实现同时持有 GDI 位图、托管字节数组和 DIB，并在每帧做两次完整拷贝。相同画布下像素缓冲减少三分之二；这是缓冲大小，不是进程工作集降幅。
- 几何、字体、画笔、画刷和图标按配置版本、方案、层级、DPI/画布缓存；高亮只清除并重绘旧/新扇区及中心的受影响区域。二级菜单可见范围改变时完整重绘。半透明内容先清除区域再绘制，避免叠色、光晕残留。
- 没有后台动画、帧计时器或闲置重绘。隐藏后启动 30 秒一次性计时器；再次显示立即取消。到期释放场景和像素缓冲，保留轻量 HWND/DC，再次使用按需重建；退出释放全部资源。旧手势的延迟关闭不能隐藏当前手势。
- 无二级动作时不预留较大的子环画布。DPI 放大和画布贴边继续使用原生窗口坐标；触点方向仍以原始触摸中心为基准。
- 原始触摸报告复用最多 64 KiB 的原生输入缓冲、触点集合和笔接近过期列表；触点位置只换算一次，再用于识别与中心计算。日志线程按事件唤醒。常规关闭控制台和静默启动使用 `TrimMemory(force: false)`，不强制清空物理工作集。

## 可复现验证

`scratch/WheelRenderTests` 用独立进程加载指定版本 DLL，在隐藏 HWND 上测试，不显示 GUI、不安装钩子、不发送输入、不调用强制 GC 或工作集整理。可同时用于已归档的 `touch.2` 和新版本：

```powershell
dotnet build scratch/WheelRenderTests -c Release --artifacts-path scratch/wheel-tools-check -p:UseSharedCompilation=false -nodeReuse:false
dotnet scratch/wheel-tools-check/bin/WheelRenderTests/release/WheelRenderTests.dll <StarPie.dll绝对路径> <新结果目录> verify
```

旧版本只运行不带 `verify` 的基准。基准为相同 482×482 画布上的 240 次方向高亮变化，分别记录耗时分位数、进程 CPU、临时分配和像素缓冲大小；首帧包含 JIT/字体初始化，不代表实际触摸唤出延迟。不要并行跑对照进程。报告和 PNG 随本地发行归档保存，数字以报告为准。

验证包含主题/样式/形状组合、4/8/12 方向、图标与二级菜单、DPI、直接像素存储、增量与完整重绘的像素一致性、缓存失效、隐藏释放/重建、重复释放、GDI 句柄稳定性和 WPF 画刷冻结。另运行触控识别和智识插件回归。沙箱保留，不运行会批量删除沙箱的旧插件自检。

实机仍需检查四个屏幕朝向、边缘呼出、实际取词/OCR、鼠标与触摸交替、连续动作、30 秒后再次呼出，以及控制台关闭后的进程工作集和 CPU。完整 GUI 回归按 AGENTS.md 由用户手动运行。此次离屏结果不能证明整机占用目标、首帧小于 16 毫秒或 120 FPS 已达成。

## 本地对照结果（2026-10-01）

同机以三个交替进程对照，每进程 240 次重绘，画布固定为 482×482，结果取三个进程报告的中位数：

| 指标 | touch.2 | touch.3 | 降幅 |
| --- | ---: | ---: | ---: |
| 单帧耗时中位数 | 1.823 ms | 1.1852 ms | 34.99% |
| 单帧 p95 | 5.2904 ms | 3.1969 ms | 39.57% |
| 240 帧进程 CPU 时间 | 578.125 ms | 390.625 ms | 32.43% |
| 240 帧临时托管分配 | 299960 bytes | 29408 bytes | 90.2% |
| 像素缓冲 | 2.78789e+06 bytes | 929296 bytes | 66.67% |

这些数字仅代表隐藏窗口上的对照负载；完整程序物理工作集没有受控对照，首次字体/JIT 初始化和实际触屏延迟仍需实机测量。362 项轮盘外观/生命周期检查、222 项智识回归和 12 项触控识别检查通过，均为离屏或模型级验证。
